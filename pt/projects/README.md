# Projetos

A Superteam Brasil constrói bens públicos para o ecossistema Solana. Nosso trabalho open-source abrange ferramentas para desenvolvedores, padrões de protocolo, plataformas educacionais e implementações de referência.

A organização solanabr no GitHub reúne 35+ repositórios originais (~75 incluindo forks de recursos de aprendizado curados); estes são os projetos principais -- cada um voltado para uma lacuna na experiência do desenvolvedor Solana.

## Projetos Principais

| Projeto | Descrição |
|---------|-----------|
| [Solana AI Kit](solana-claude.md) | Configuração de AI coding (compatível com Claude Code e Codex) para desenvolvimento full-stack em Solana |
| [Superteam Academy](superteam-academy.md) | Sistema de gestão de aprendizado on-chain com credenciais verificáveis |
| [Wiki](wiki.md) | Hub de conhecimento trilíngue da Superteam Brasil |
| [Solana Vault Standard](solana-vault-standard.md) | Interface padronizada de vaults para Solana -- 12 variantes rodando na devnet |
| [Solana Stablecoin Standard](solana-stablecoin-standard.md) | Interface padronizada para emissão e gestão de stablecoins |
| [Solana Game Skill](solana-game-skill.md) | Pacote de skill do Claude Code para jogos em Unity e mobile na Solana |
